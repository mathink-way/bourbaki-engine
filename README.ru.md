# bourbaki-engine

[English](README.md) | **Русский**

Глава I "Теории множеств" Н. Бурбаки как программа. Доказательства пишутся так, как они
написаны в книге, а программа проверяет каждую строку и по запросу раскрывает её до явных
аксиом, схем и силлогизма. Типов нет, есть только то, что есть у Бурбаки: знакосочетания
с τ и □, термы, соотношения, теории, схемы, доказательства.

```
theorem C8 {A : rel} : A ⇒ A {
  A ⇒ (A ∨ A)                                  by S2 with A := A; B := A
  (A ∨ A) ⇒ A                                  by S1 with A := A
  ((A ∨ A) ⇒ A) ⇒ ((A ⇒ (A ∨ A)) ⇒ (A ⇒ A))    by S4 with A := A ∨ A; B := A; C := ¬A
  (A ⇒ (A ∨ A)) ⇒ (A ⇒ A)                      by mp 2 3
  A ⇒ A                                        by mp 1 ^
}
```

Строки нумеруются сами, `^` это предыдущая строка. Дальше `by C8` это один шаг в любом
доказательстве, подстановку можно не писать, если её видно из строки.

## Быстрый старт

Нужен Rust (1.85 или новее, `rustup`).

```
git clone https://github.com/mathink-way/bourbaki-engine && cd bourbaki-engine
cargo install --path .              # команды bourbaki и bourbaki-lsp
bourbaki check konspekt/*.bk        # проверить весь конспект
bourbaki expand konspekt/02_quant_eq.bk ch1.T1   # раскрыть теорему до S1-S7 и C1
bourbaki check файл.bk --prefix     # печатать в польской записи Бурбаки
```

Без установки то же самое: `cargo run --release -- check konspekt/01_logic.bk`.

Свой файл начинается так:

```
import "00_prelude.bk"     -- схемы S1-S7, теории Logical, Quantified, Egalitarian (пространство имён base)
import "01_logic.bk"       -- критерии C6-C21 (пространство имён ch1)
open base
open ch1
in Logical

theorem my_first {A B : rel} (h : B) : A ⇒ B {
  B ⇒ (¬A ∨ B)   by C7
  A ⇒ B          by mp h ^
}
```

Путь в `import` считается от папки файла. Импорт не вставляет текст: импортированный файл
проверяется один раз, в своём чистом состоянии, а его объявления становятся доступны под
полными именами (`ch1.C7`, `base.S1`).

## Язык за две минуты

| что                                 | как пишется                                                  |
|-------------------------------------|--------------------------------------------------------------|
| метапеременные (жирные буквы книги) | `{A B : rel}`, `{T : term}`, `{R : rel 1}` (это R{x}, пишется `R(x)`) |
| гипотезы                            | `theorem T {A B : rel} (h : A ⇒ B) : ...`                     |
| схема                               | `by S5`, `by S4 with A := P; B := Q; C := ¬P`                 |
| доказанная теорема                  | `by C6 1 ^` (ссылки это строки с её гипотезами)               |
| силлогизм C1                        | `by mp 2 3`                                                  |
| C14 (вспомогательная гипотеза)      | `A ⇒ B by assume h { ... }`                                  |
| C15 (от противного)                 | `A by contra g { ... }`                                      |
| C27 обобщение, C3 подстановка       | `by gen ^ with x`, `by subst ^ with x := T`                  |
| тавтология (упр. 7)                 | `by taut`                                                    |
| пропуск                             | `by sorry` (теорема помечается)                              |
| свои знаки и сокращения             | `sign ∈ [\in] : rel 2 infix`, `abbrev ⊂ (X Y : term) infix := (∀z)(z ∈ X ⇒ z ∈ Y)` |
| сокращение, связывающее букву       | `abbrev Coll (R : rel 1) := (∃y)(∀x)(x ∈ y ⇔ R(x))`, пишется `Coll_x(x ∈ a)` |
| теории                              | `theory Set extends Egalitarian { signs ∈ ; schemes S8 ; axiom A1 : ... }` |
| модели (C5)                         | `model M : G -> H with a := T { A1 by ... }`, `transfer thm via M` |
| имена                               | `namespace ch1 ... end`, `open ch1`, `alias imp_trans := ch1.C6` |
| запись формул                       | `#set infix` (по умолчанию) или `#set prefix` (польская, `∨ ¬ A B`) |
| команды                             | `#show`, `#signs`, `#formation`, `#print`, `#expand`, `#log`, `#format` |

Значки можно набирать словами и командами LaTeX: `\forall x \exists y (x \in y \to y \in x)`.
Полное описание: [docs/FORMAT.md](docs/FORMAT.md).

## Редактор

`bourbaki-lsp` это языковой сервер (LSP): ошибки подчёркиваются при каждом изменении
файла, наведение на имя показывает теорему, схему, сокращение или знак. Подойдёт любой
редактор с LSP. Готовые расширения с подсветкой: [VS Code](vscode/README.md) и
[Zed](zed/README.md), установка описана там.

## Как это устроено

Коротко:

1. **Знакосочетания хранятся деревом с общими частями** (□ это индексы де Брёйна). В
   буквальной записи (∃x)R растёт экспоненциально, дерево линейно; тождественность
   знакосочетаний это равенство деревьев.
2. **Метапеременные это специальные знаки.** Теорема с A доказана в 𝒯 + знак A; замена
   знака соотношением переводит доказательство в доказательство. Поэтому применить
   теорему значит подставить в её формулировку, а не проверять доказательство заново.
3. **Метатеоремы** (C14, C15, C27, C3, тавтологии, C5) проверяются по условиям, а их
   конструктивные доказательства из книги запускаются при раскрытии.
4. **Раскрытие проверяется независимо**: `Demonstration::verify` знает только
   определение доказательства из § 2.

Подробно: [docs/HOW_IT_WORKS.md](docs/HOW_IT_WORKS.md).

## Устройство репозитория

```
konspekt/        конспект (.bk), проверяется тестами
docs/            FORMAT.md (формат), HOW_IT_WORKS.md (устройство), DOCS.md (LaTeX в документации)
src/             ядро: expr.rs (знакосочетания), formative.rs (CF), theory.rs (теории, схемы),
                 proof.rs (теоремы и доказательства), logic.rs / quant.rs / equality.rs (критерии)
src/konspekt/    язык: parse.rs, check.rs, model.rs (C5), mod.rs (имена, импорт, команды)
src/main.rs      команда bourbaki;  src/bin/bourbaki-lsp.rs  языковой сервер
tests/           тесты, в том числе весь конспект и разговор с LSP
vscode/          расширение VS Code (подсветка и языковой сервер)
zed/             расширение Zed и грамматика подсветки
examples/        тур по ядру на Rust: cargo run --example tour
```

## Разработка

```
cargo test                      # все тесты (конспект, раскрытия, LSP)
cargo clippy --all-targets
cargo doc --open                # документация; раздел book это конспект, формулы через KaTeX
```

В комментариях конспекта и в документации можно писать LaTeX, см.
[docs/DOCS.md](docs/DOCS.md). Тексты в коде и сообщения об ошибках по-русски.

## Состояние и ограничения

* Глава I целиком и начало главы II. Это учебный проект: формализовать книгу, чтобы
  потрогать её руками, а не промышленный язык доказательств.
* Раскрытия поздних теорем огромны (C40, C42 больше 100 тысяч строк), раскрытие C51 не
  помещается в 6 ГБ памяти. Быстрая проверка от этого не зависит.
* Подстановку для схем вида S6 (R стоит только как R(T)) нужно писать.
* Пошагового раскрытия нет. Расширение для VS Code пока не запускалось в самом VS Code
  (пакет собирается, подсветка проверена библиотекой `vscode-textmate`).

## Лицензия и книга

Код и тексты этого репозитория распространяются по лицензии MIT ([LICENSE](LICENSE)).

Репозиторий не содержит текста книги. Конспект это собственный пересказ: формальные
утверждения, нумерация критериев (C1-C51, S1-S8) и ссылки на страницы русского перевода
(Н. Бурбаки, "Теория множеств", М.: Мир, 1965). Математические утверждения и идеи не
охраняются авторским правом, текст книги и перевода охраняется, поэтому сканы и длинные
цитаты сюда не кладутся. Проект никак не связан с объединением Бурбаки и правообладателями.
