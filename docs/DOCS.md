# Как писать конспект и документацию (и где работает LaTeX)

## Конспект `.bk` становится книгой

`cargo doc --open`, раздел `book`: каждый файл `konspekt/*.bk` это страница. Страницы
собирает `build.rs`, новый файл появляется сам (имя модуля это имя файла без номера:
`05_quant.bk` даёт `book::quant`). Правила простые:

* комментарий `--` в начале строки становится текстом; каждая строка остаётся строкой,
  пустой комментарий `--` или пустая строка начинают новый абзац;
* комментарий с отступом после `--` (`--   import ...`) показывается как код;
* всё остальное (объявления, теоремы, комментарии внутри доказательств) показывается
  как код, ровно как в файле.

Принятая схема текста в начале файла: "Задача -> Проблема -> Решение -> Что осталось".

## LaTeX

В тексте конспекта (комментарии в начале строки) работают формулы KaTeX:

```
-- По определению (∃x)R есть $(\tau_x(R) \mid x)\,R$, а схема S5 говорит
-- $$ (T \mid x)\,R \Rightarrow (\exists x)\,R . $$
```

Формулы между `$` передаются KaTeX как есть: `build.rs` сам экранирует `_`, `*`, `\{`,
`\,` и прочее, что иначе съел бы markdown.

В документации к коду (`///` и `//!` в `.rs`) KaTeX тоже подключён, но там текст сразу
читает markdown, поэтому:

* простые формулы пишутся как есть: `$x \in X$`, `$\tau_x(R)$`;
* обратная косая черта перед знаком препинания съедается (`\{`, `\,`, `\|`): удвойте её
  (`\\{`) или используйте блок ```` ```math ````, внутри которого ничего не экранируется:

````
/// ```math
/// \{x \mid R\} = \mathcal{E}_x(R)
/// ```
````

Как подключено: `katex-header.html` вставляется в каждую страницу документации
(`.cargo/config.toml` для `cargo doc`, `[package.metadata.docs.rs]` в `Cargo.toml` для
docs.rs). Нужен интернет: KaTeX грузится с jsdelivr.

На GitHub формулы `$...$` и блоки ```` ```math ```` в файлах `.md` показываются сами.

## Формулы в самих доказательствах

Формулы в строках доказательства это не LaTeX, а запись Бурбаки, но набирать можно и
командами LaTeX: `\forall x \exists y (x \in y \to y \in x)` это то же, что
`(∀x)(∃y)(x ∈ y ⇒ y ∈ x)`. Таблица значков: `docs/FORMAT.md`, раздел "Набор значков".
