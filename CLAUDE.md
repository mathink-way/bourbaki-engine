# bourbaki-engine: заметки для Claude

Реализация главы I "Теории множеств" Бурбаки (рус. пер. 1965) на Rust и главы II, §§ 1-6.
Зависимости: `ariadne` (ошибки в CLI), `lsp-server` + `serde_json` (языковой сервер).
Автор математик (3 курс), в Rust новичок: объяснять решения по-математически, код держать простым.

## Принципы (не нарушать)

- Ядро это `proof.rs`: `Theorem` создаётся только через `axiom`, `scheme`, `mp` и
  метатеоремы, которые перестраивают доказательство (C2/C3 `subst_c2`/`subst`, C4 `lift`/`lift_with`,
  C14 `discharge`, C5 `Interpretation`). Никаких других способов получить `Theorem`.
- Всякое новое правило вывода = функция, строящая доказательство из S1-S7 и C1.
  Добавив критерий, проверить в тесте `thm.demonstration().verify()`.
- `Term`/`Relation` создаются только конструкторами-критериями CF1-CF12 из `formative.rs`.
- Нумерация и названия как в книге: C6, CF8, S5, "явная аксиома", "константа теории".
- Тождественность знакосочетаний = структурное равенство `Expr` (де Брёйн, подсказка имени в τ не участвует).
- Тексты (комментарии, сообщения об ошибках, документация) по-русски, без длинных тире, кавычки прямые "".

## Карта

- `sign.rs` знаки, `assembly.rs` буквальные строки со связями и Приложение,
  `expr.rs` дерево, `formative.rs` CF, `theory.rs` теории и S1-S7,
  `proof.rs` ядро, `logic.rs` § 3, `quant.rs` § 4, `equality.rs` § 5, `syntax.rs` печать/разбор.
- `src/main.rs` CLI `bourbaki`, `src/bin/bourbaki-lsp.rs` LSP, `zed/` и `vscode/` расширения,
  `examples/tour.rs` тур по ядру, `tests/` тесты.

## Команды

- `cargo test`, `cargo run`, `cargo clippy`.
- Размер доказательства: `thm.demonstration().len()`. C14 умножает размер примерно в 40 раз,
  поэтому в библиотечных леммах предпочитать прямые выводы (`pre_inner`, `post_inner`, `imp_mp2`).

## Язык конспектов

Сделан: `src/konspekt/`, формат в `docs/FORMAT.md`, устройство в `docs/HOW_IT_WORKS.md`,
конспект в `konspekt/*.bk` (проверяется тестом `tests/konspekt.rs`). Исходная постановка
задачи: `docs/history/LANGUAGE_SPEC.md`. README на английском (`README.md`) и русском
(`README.ru.md`), держать их согласованными.

- Прелюдия в пространстве имён `base`; файлы пишут `import "00_prelude.bk"` и `open base`.
  `Konspekt::with_prelude` (для тестов и API) открывает `base` сам. CLI и LSP начинают с
  пустого `Konspekt::new()`.
- Внутреннее имя схемы короткое (`S5`), полное (`base.S5`) только для поиска; в одной теории
  две разные схемы с одним коротким именем запрещены. `Theory::is_logical` сверяет S1-S4
  с книгой подстановкой, не по имени.
- `build.rs` превращает `konspekt/*.bk` в страницы `book` для `cargo doc` (комментарии в
  начале строки становятся текстом, формулы `$...$` экранируются для KaTeX).
  KaTeX: `katex-header.html`, `.cargo/config.toml`, `[package.metadata.docs.rs]`.

- Метапеременные = специальные знаки (вес 0 для A, вес 1 для R{x}); применение теоремы
  = `Expr::replace_signs` в формулировке, раскрытие = `Theorem::instantiate_signs`.
- Схемы задаются образцами (`PatternScheme`), в образце не должно быть свободных букв.
- Быстрая проверка и раскрытие идут одним кодом (`check.rs`, флаг `expand`).
- Сначала пробовать оформить новое "правило" теоремой с гипотезами в конспекте (так сделан
  C19: `ch1.C19`, `ch1.obtain`). Новое правило языка только если теоремой не сказать: добавить
  вариант в `ast::Just`, разбор в `parse.rs`, проверку и раскрытие в `check.rs`, тест в
  `tests/konspekt.rs` (и положительный, и с ошибкой).
- Синтаксис английский (`theorem`, `by`, `with`, `namespace`, `open`, `alias`, `#set`);
  сообщения об ошибках по-русски.
- Запись формул одна на файл (`Scope::notation`): `Infix` или `Prefix`, чужая форма это ошибка.
- Имена: `Konspekt::resolve_in` (пространство имён, объемлющие, `open`, алиасы).
  Теорема хранит `Names` (пространство, `open`, запись), раскрытие использует их же.
- Ошибки в CLI печатает `ariadne` (позиции в байтах: `IndexType::Byte`).
- Сокращения со связанной буквой (`Coll_x(...)`): параметры веса k, `Abbrev::binders`,
  лексема `Tok::Binder`. Параметры переименовываются в свежие знаки `имя#параметр`.
- `Expr::match_into` / `match_many`: образцы Миллера для метапеременных веса k, отложенные
  вхождения R(T), догадки по τ-подвыражениям (`solve`). Используется и при выводе
  подстановки в шагах, и при печати сокращений. Найденное всегда проверяется буквально.
- Модели C5: `konspekt/model.rs` (`model ... { A1 by ... }`, `transfer`), раскрытие через
  `Interpretation`. У теоремы поле `origin` (доказана или перенесена).
- Замеры: `BOURBAKI_TIME=1` (время теорем), `BOURBAKI_TIME_LINES=1` (строки дольше 10 мс),
  `BOURBAKI_TIME_USE=1` (фазы применения теоремы), `BOURBAKI_DBG=1` (долгие сопоставления).
- Глава II написана через графики: отображение это график F с Map(F, A, B), значение ap(F, x),
  семейство это терм с выделенной буквой {X : term 1}, эквивалентность это график G с Equiv(G, E).
- Раскрытия поздних критериев огромны (C40, C42 больше 100 тысяч строк); в тестах
  раскрываются выборочно (`later_chapters_expand_and_verify`).
